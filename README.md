# Sprint_6

test_order.py
Тесты, проверяющие оформление заказа:
- Проверка ввода имени, фамилии, адреса, телефона.
- Выбор станции метро.
- Указание даты аренды и срока.
- Выбор цвета самоката и ввод комментария.
- Нажатие кнопки «Заказать» и подтверждение заказа.
- Проверка отображения окна с успешным сообщением.

test_questions.py
Тесты блока FAQ (часто задаваемых вопросов):
- Проверка клика по каждому вопросу.
- Раскрытие и отображение ответа.
- Проверка соответствия текста вопроса и ответа.
- Всего проверяется 8 вопросов на главной странице.
